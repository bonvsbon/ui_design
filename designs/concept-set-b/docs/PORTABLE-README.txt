GAMBOL — PORTABLE / ทั้ง 5 คอนเซปต์
====================================

วิธีเปิด
1. แตกไฟล์ GAMBOL-Portable-All-5.zip ก่อน
2. ดับเบิลคลิก GAMBOL-All-5-Concepts.html เพื่อเปิดหน้ารวม
3. หรือเปิดไฟล์ Concept-01 ถึง Concept-05 เพื่อเริ่มที่แบบที่ต้องการ

ไฟล์ HTML ทุกไฟล์มีโค้ด รูปภาพ และฟอนต์ครบในตัว
จึงคัดลอกไฟล์ HTML เพียงไฟล์เดียวไปเปิดเครื่องอื่นได้
ไม่ต้องติดตั้ง Node.js ไม่ต้อง npm install และไม่ต้องเปิดเซิร์ฟเวอร์
รองรับการเปิดออฟไลน์ในเบราว์เซอร์เดสก์ท็อปรุ่นปัจจุบัน เช่น Chrome

ไฟล์ที่ได้รับ
• GAMBOL-All-5-Concepts.html — หน้ารวมและตารางเปรียบเทียบ
• Concept-01-Premium-Street.html — Modern Minimal / Premium Street
• Concept-02-Bold-Sport.html — Bold Sport / Energy
• Concept-03-Lifestyle-Stories.html — Lifestyle Storytelling
• Concept-04-Smart-Commerce.html — Find Your Pair / Smart Commerce
• Concept-05-Future-Footwear.html — Innovation / Future Footwear

ทุกไฟล์สลับดูครบ 5 แบบได้จากแถบบน และมีหน้ารวมสินค้า
หน้ารายละเอียดสินค้า ระบบค้นหา ตัวกรอง Wishlist ตะกร้า และ Content Studio
URL จะใช้ # เพื่อให้เปลี่ยนหน้าและรีเฟรชได้โดยไม่ต้องมีเซิร์ฟเวอร์
ทดสอบการเปิดจาก file:// โดยปิดเครือข่ายใน Chrome แล้ว

การทดลองใช้งาน
• คลิก Shop เพื่อดูสินค้า และคลิกสินค้าเพื่อเลือกสี/ไซซ์
• ค้นหาได้จาก Search หรือ Cmd/Ctrl + K
• เปิดไอคอนตั้งค่าด้านบนเพื่อเปลี่ยนแคมเปญและลำดับส่วนต่าง ๆ
• การแก้ไขเก็บไว้ในเบราว์เซอร์ เมื่อส่งไฟล์ให้ผู้อื่นจะเริ่มจากข้อมูลตั้งต้น
• การจำข้อมูลหลังปิดไฟล์ขึ้นอยู่กับสิทธิ์จัดเก็บของเบราว์เซอร์
• ลิงก์แผนที่ Instagram และเว็บไซต์ภายนอกต้องใช้อินเทอร์เน็ต

ขอบเขต
เป็น frontend prototype ใช้ข้อมูลสินค้า ราคา และนโยบายตัวอย่าง
ไม่มี backend ไม่มีบัญชีผู้ใช้จริง และไม่รับชำระเงินจริง
ภาพและฟอนต์ใช้เพื่อพรีวิวงานออกแบบ ดูที่มาภาพใน ASSET-CREDITS.md
ใบอนุญาตฟอนต์อยู่ในโฟลเดอร์ Licenses และฝังไว้ในไฟล์ HTML ทุกไฟล์

English quick start
Unzip the package, then double-click any HTML file in Chrome.
Each HTML is self-contained, includes all five concepts, and works offline.
The individual files simply start at a different concept.
No server or installation is required. External links need internet access.
